# Fire and Electric Safety — Landing Page

Statutory Fire Safety & Electrical Risk Audits landing page engineered to codal precision (NBC 2016 Part 4, TAC, IS 2189, NFPA 101).

## Live Deployment
Deployable directly on [Vercel](https://vercel.com).

## Project Structure
- `index.html` - Primary production landing page
- `fire.html` - Standalone fire safety page
- `assets/`
  - `css/` - Stylesheets (`fire.css`)
  - `images/` - Visual assets and diagrams
- `vercel.json` - Vercel deployment configuration
